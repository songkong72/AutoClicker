# 관리자 명단(서버) 설정

앱에 "관리자 관리"가 들어갔다. 서버(Firebase)에 개발자와 관리자 명단을 두고, 개발자가 관리자 코드를 만들어 사람마다 관리자 권한을 주고 뺏는다.
**서버 규칙을 적용하기 전에는 이 기능이 동작하지 않는다.** 관리자 비밀번호 로그인은 없어졌고, 관리자는 개발자가 만든 코드(`AD-…`)로만 들어온다.

## 1. 서버 규칙 적용 (한 번)

1. Firebase 콘솔 → Realtime Database → **규칙** 탭을 연다.
2. 저장소의 `database.rules.next.json` 내용을 전체 복사해 붙여 넣고 **게시**한다.
3. 이 규칙은 기존 규칙(`rallyRooms`, `rallyMembers`)을 그대로 두고 `owners`, `admins`, `adminCodes`만 더한 것이다. 집결 방 동작은 달라지지 않는다.

## 2. 개발자 등록

1. 최신 APK를 설치하고, 관리자 로그인 창(앱 위쪽 관리자 아이콘)의 **내 기기 ID** 버튼을 눌러 ID를 복사한다. (비밀번호 로그인은 없어졌다.)
2. 복사한 ID를 아래 3번처럼 콘솔에 등록한다.
3. Firebase 콘솔 → Realtime Database → 데이터에서 루트에 `owners`를 만들고, 그 아래에 키를 복사한 ID, 값을 `true`로 적는다.
4. 앱 관리자 로그인 창에서 **칸을 비우고 확인**을 누르면 개발자로 들어온다. 관리자 메뉴 → **관리자 관리**가 열리면 성공이다.

앱을 지우고 다시 설치하면 기기 ID가 바뀐다. 그때는 2~3을 다시 하고, 옛 ID는 콘솔에서 지운다.

## 3. 관리자 추가와 삭제

- 추가: 관리자 관리 → **+ 관리자 코드 만들기** → 이름표를 적으면 코드(`AD-XXXXXXXX`)가 만들어지고 안내 문구가 복사된다. 카카오톡으로 보낸다. 받은 사람은 앱의 관리자 로그인에 그 코드를 넣는다. 코드는 한 번만, 만든 지 24시간 안에만 쓸 수 있다.
- 삭제: 관리자 관리 → 관리자 줄의 **삭제**. 삭제된 폰은 다음에 앱을 열 때 팀장 화면으로 돌아간다.
- 대기 중인 코드는 **코드 복사**나 **취소**를 할 수 있다.

## 관리 화면 기능

- **여러 명 코드 한꺼번에**: 이름표를 줄바꿈으로 여러 줄 적으면(최대 10명) 사람마다 코드를 만들고, 사람별 안내 문구를 한 번에 복사한다.
- **코드 기간 고르기**: 1시간 / 24시간 / 7일. 코드는 한 번만 쓸 수 있다.
- **이름 수정**: 관리자 줄의 "이름 수정". 이름표는 관리자 항목에 저장된다.
- **마지막 접속과 앱 버전**: 관리자가 앱을 열 때마다 서버에 적는다. 최신 앱으로 업데이트한 관리자부터 보이고, 그 전에는 "접속 기록 없음 · 버전 알 수 없음"으로 나온다.
- **쓰인·만료 코드 정리**: 서버에 쌓인 코드를 지운다. 지우기 전에 관리자 이름표를 먼저 저장한다.
- **방 전체 목록(개발자 전용)**: 서버의 모든 방을 목록으로 본다. 군단 수, 팀장 배정 수, 진행 상태, 명단 인원이 보이고 방을 누르면 군단별 팀장·행군시간과 명단 이름이 나온다(읽기 전용). 규칙에서 개발자(`owners`)만 `rallyRooms`와 `rallyMembers`를 통째로 읽을 수 있다. 관리자와 일반 사용자는 자기 방만 읽는다.
- 앱 버전은 빌드할 때 git에서 자동으로 정해진다(`1.0.<커밋 개수>`). "내 기기 ID" 창에서도 볼 수 있다.

새 기능(이름 수정, 접속·버전)은 **규칙을 다시 게시해야** 동작한다. `database.rules.next.json` 전체를 콘솔 규칙 탭에 다시 붙여 넣고 게시한다.

## 지금 단계의 한계 (중요)

- 기존 집결 방 규칙은 아직 "로그인한 누구나 쓸 수 있음"이다. 그래서 명단에서 지워도, 앱을 고쳐 쓰는 사람이 방에 쓰는 것까지 서버가 막지는 못한다. 지워진 사람의 앱 화면에서 관리자 기능이 사라질 뿐이다.
- 완전히 막으려면 다음 단계가 필요하다: 모든 관리자를 코드로 다시 등록 → 방 쓰기 규칙을 "관리자 명단에 있는 사람만"으로 좁히기(팀장은 자기 행군시간만) → 비밀번호 로그인 없애기. 이 순서를 어기면 현재 관리자들이 갑자기 방을 못 쓰게 되므로, 단계마다 확인하며 진행한다.
