# 할 일

어느 대화에서 작업하든 **먼저 이 파일을 읽고**, 제안·결정·끝낸 일을 여기에 적는다.
끝낸 일은 "끝낸 일"로 옮기고 커밋 번호(앞 7자리)를 붙인다. 번호는 바꾸지 않는다(대화에서 번호로 부른다).

## 폰에서 확인할 것
- **조 머리띠 글자(사용자 화면에서 "1조 … 먼저 도착"으로 잘림, 2026-10-11)**: 펼친 보기(편집 아님)에서는 "군단 N개"를 적지 않는다. "…"가 더 보이지 않는지, 머리띠 왼쪽에 화살표가 보이는지. 접으면 "군단 N개"가 나타나고 오른쪽 글은 짧아지는지("20초 뒤 도착").
- **접기(2026-10-11, 시안 "집결 패널 개선안" 맨 아래 줄 "접기")**
  - 편집 화면의 "방 설정 ▾"을 누르면 한 줄("▸ 방 설정 … 집결 대기 5분 · 이동 준비 15초")로 접히고, 다시 누르면 펴지는지. 접으면 군단 목록이 두 줄쯤 더 길어지는지. 패널을 닫았다 열어도 접은 상태가 남는지.
  - 조 머리띠(화살표·"2조"·"군단 N개" 쪽)를 누르면 그 조가 접히고 화살표 방향이 바뀌는지. 접힌 상태에서도 −/+ 로 도착 간격을 바꿀 수 있는지(−/+ 를 눌렀는데 접히지는 않는지). 진행 중에도 접고 펼 수 있는지.
  - 군단 6개 이상, 조 3개일 때: 조 머리띠와 상관없이 군단이 5줄 보이고 나머지는 목록 안에서 밀리는지. "집결 시작"이 화면 밖으로 나가지 않는지.
  - 집결장 폰에서 내 조를 접으면 내 군단 줄(행군 시간 고치기)도 숨는다. 불편하면 알려 달라.
- **군단 줄의 작은 글씨를 조 단위로(사용자 요청, 2026-10-11)**: 조를 쓰는 방에서 "먼저 클릭 / N초 뒤"가 같은 조 안에서만 견준 값인지(예: 2조에 3군 혼자면 "먼저 클릭"). 조 사이의 차이는 머리띠의 "N분 뒤 도착"으로만 보인다. 누르는 시각 자체는 바뀌지 않았다.
- **앱 안의 사용 설명서(2026-10-11)**: 첫 화면 오른쪽 위 열쇠 왼쪽에 "설명서" 글자가 보이고(제목이 잘리지 않는지), 누르면 설명서가 열리는지. 위의 차례(처음 준비·일반 연타…)와 역할 카드, 표 안의 링크를 누르면 그 자리로 가는지. "↑ 맨 위로", 뒤로 가기(먼저 설명서 안에서 되돌아가고 그다음 닫힘), "닫기"가 되는지. 지휘관 메뉴(관리)에도 "사용 설명서"가 있는지. 폰이 어두운 모드여도 설명서는 밝게 보이는지. 내용 중 실제 화면과 다른 말이 있으면 알려 달라.
- **"전원 도착"이 일찍 뜨던 것(사용자 보고, 2026-10-11)**: 지휘관이 1조 군단을 맡은 방에서, 1조가 닿은 뒤에도 2조가 가는 중이면 위 칸이 "2조 행군 중 0:16"으로 이어지고 단계 표시도 "행군"인지. 마지막 조까지 닿아야 "전원 도착"이 되는지. 집결장 폰은 "내 군단 도착 · 2조 행군 중 0:16"으로 보이는지.
- **패널 묶음 구분(2026-10-11, 시안 "집결 패널 개선안" 맨 아래 줄 "묶음 구분 개선안")**
  - 편집 화면: 상태 / 군단 / 방 설정이 각각 테두리 있는 칸으로 나뉘어 보이는지. 맨 위 칸 첫 줄이 "● 지휘관 시작 대기 중"(왼쪽)과 "방 11211"(오른쪽)인지, 그때 아래 내 기기 줄에는 방 번호가 빠지는지.
  - 조를 쓰는 방: 조마다 상자 하나이고 머리띠에 흰 "2조" 딱지, "군단 N개", 동그란 −/+ 와 흰 글씨 "2분 뒤 도착"이 보이는지(노랑 아님). 글자가 잘리거나 두 줄로 넘어가지 않는지.
  - 모두 1조인 방: 머리띠 없이 군단 줄이 상자 하나에 들어 있는지.
  - 군단 줄을 펼쳤을 때(조 고르기, 행군 시간, 보정, 삭제) 상자 안에서 어색하지 않은지. 내 군단 줄 강조가 보이는지.
  - 집결 진행 중: 큰 숫자, 단계 표시, 막대가 칸 안에 들어가 있는지. 접으면(알약) 전과 같은 모양인지, 다시 펴면 칸이 돌아오는지.
  - 군단이 많을 때(6개 이상, 조 3개): 목록이 안에서 밀리고 아래 "집결 시작"이 화면 밖으로 나가지 않는지. 패널이 전보다 조금 길어졌다. 답답하면 알려 달라.
- 조를 골랐는데 바로 1조로 되돌아가는 경우(사용자 보고, 2026-10-11): 서버가 저장을 거절해 되돌린 것으로 본다(새 규칙을 아직 게시하지 않았을 때). 이제 "조를 저장하지 못했어요. 서버 규칙을 새로 게시해야…" 안내가 뜬다. 규칙을 게시한 뒤에도 되돌아가면 알려 달라(그때는 다른 원인).
- 군단 삭제 자리: 펼친 군단 줄의 머리에서 빨간 ✕가 없어지고, 펼친 부분 맨 아래 오른쪽에 "1군 삭제" 글자 버튼이 보이는지. 누르면 "한 번 더 누르면 삭제"로 바뀌고 다시 눌러야 지워지는지. 조 버튼 줄이 머리 줄과 겹쳐 보이지 않는지.
- **조(도착 간격) — 먼저 서버 규칙을 게시해야 한다**(`database.rules.next.json`, 방법은 `docs/관리자-서버-설정.md`). 게시 전에는 조를 쓰는 순간 "저장하지 못했어요"가 뜬다. 조를 쓰지 않는 방은 게시 전에도 전과 같다. **지휘관과 집결장 모두 새 버전이어야 한다**(옛 버전 집결장 폰은 도착 간격을 모르고 일찍 누른다).
  - 지휘관 편집 화면: "조 나누기"(2·3·5개씩, 모두 1조로)가 "+ 군단 추가" 왼쪽에 보이는지. 군단 줄을 펼치면 맨 위에 "조  1조 2조 3조 4조 5조"가 한 줄로 보이고, 누르면 그 군단이 그 조 제목 아래로 옮겨 가는지.
  - 조 제목 줄: 1조는 "먼저 도착 (기준)", 2조부터는 − / "1분 뒤 도착" / + (10초씩, 값을 누르면 직접 입력). 편집을 끝내면 "1분 뒤 도착 · 시작 후 7:00"처럼 보이는지.
  - 대기 중 큰 숫자가 가장 먼저 닿는 조의 도착까지이고, 아래 줄이 "1조 도착까지 · 2조 +1분 · 3조 +2분"인지.
  - 집결 시작 한 번으로 2조·3조 폰이 각각 1분·2분 늦게 누르는지(폰 3대 이상). 조 제목 줄에 "도착까지 5:32 · 11:17:00"이 보이는지.
  - 군단이 없는 지휘관 폰: 큰 숫자가 "1조 집결 중 4:32" → 1조 도착 뒤 "2조 …"로 넘어가는지. 접힌 알약도 같은지.
  - 집결장 폰: 큰 숫자는 내 군단 기준 그대로인지. 조 제목 줄은 보이되 고칠 수 없는지.
  - 모두 1조인 방: 조 머리띠가 없는지.
- 집결장 코드가 소속에 묶임(지휘관 폰 + 집결장 폰, 둘 다 새 버전): 지휘관이 "집결장 코드 발급"으로 만든 글을 집결장이 통째로 복사해 "인증하기"를 누르면 ID·코드·서버 번호·연맹 네 칸이 채워져 있는지. 인증하면 소속 표시에 🔒가 붙고, 눌렀을 때 "새 코드를 받아 다시 인증" 안내와 인증 창이 뜨는지. 연맹의 대소문자를 바꾸거나 다른 연맹을 적으면 인증이 안 되는지. 예전 코드를 넣으면 "예전 방식의 코드예요" 안내가 나오는지. **이미 인증해 둔 집결장 폰은 업데이트 뒤에도 그대로 들어가지는지**(소속도 전처럼 직접 바꿀 수 있어야 한다). 인증 창에 칸이 네 개라 키보드가 올라왔을 때 아래 버튼이 가려지지 않는지.
- 대표 바꾸기(개발자 폰): 이미 대표가 있는 연맹에서 다른 폰이 대표 신청을 하면, "연맹 대표 신청" 목록에 "지금 대표: 이름 · 마지막 접속 …. 승인하면 대표가 바뀌어요."가 보이는지. 승인하면 새 폰이 대표가 되고 예전 대표 폰은 앱을 다시 열었을 때 메뉴에서 "우리 연맹 지휘관"이 사라지는지(지휘관 화면은 그대로).
- 초대 글로 채우기(집결장 폰): 지휘관이 보낸 집결장 초대 글을 통째로 복사한 뒤 앱에서 "인증하기"를 누르면 ID와 집결장 코드가 채워져 있는지. 그대로 인증하면 소속이 글에 적힌 대로(대소문자 포함) 정해지고 방 선택에 그 소속의 방이 보이는지. 소속이 없는 폰에서 "소속 정하기"를 열었을 때도 복사한 글의 소속이 채워지는지. 안드로이드 12 이상은 "붙여넣음" 알림이 잠깐 뜰 수 있다.
- 지휘관 로그인 창 글자: 개발자 폰이 아닌 폰에서는 "개발자"라는 말 없이 "연맹 대표에게 받은 지휘관 코드를…"로 보이는지. 개발자 폰(일반 화면 미리보기 포함)에서는 전처럼 "개발자나 연맹 대표에게…"로 보인다.

자동 테스트는 통과했지만 폰에서 아직 확인하지 못한 것. 확인되면 지운다.

- 순서 클릭과 모드 버튼(시안 "단순화 시안" 6·7·8번):
  - 막대: 개방하지 않은 폰에서는 모드 버튼이 **안 보이는지**. 집결 패널 제목을 5번 연달아 누르면 "숨은 모드가 열렸어요" 알림과 함께 목록 모양 "모드" 버튼이 나타나는지. 전에 헌터를 개방해 둔 폰에서는 바로 보이는지
  - "모드 고르기" 글자 옆에 버전(예: 1.0.252)이 보이는지. 헌터를 켜면 모드 버튼이 초록, 순서를 켜면 하늘색, 끄면 회색이 되는지(2026-10-10 사용자 보고: 켜도 회색 그대로. 원인을 코드에서 찾지 못해 색 지정 방법을 하나 더 넣음)
  - 모드 버튼을 누르면 가운데에 "모드 고르기" 목록(헌터 / 저장한 순서 / + 새 순서 만들기 / 끄기)이 뜨고, 목록 밖을 누르면 닫히는지
  - 목록 창·연필 메뉴·삭제 확인 창을 잡고 끌면 옮겨지고 화면 밖으로 나가지 않는지. 옮긴 뒤 연필을 누르면 같은 자리에 다음 창이 뜨는지. 끌지 않고 짧게 누르면 줄이 그대로 눌리는지
  - 헌터: 줄을 누르면 전처럼 켜지고 버튼이 목록 모양 그대로 초록색이 되는지(깃발 그림으로 바뀌지 않음), 연필을 누르면 헌터 위치 잡기 창이 뜨는지, 발사가 전처럼 되는지
  - 새 순서 만들기: 창에 이름 칸·자리 수·자리 사이 쉬는 시간·저장이 보이고 글자가 잘리지 않는지. 이름 칸을 누르면 키보드가 올라오고 한글이 적히는지, 키보드가 창을 가려 불편하지 않은지
  - 번호 동그라미(하늘색)를 끌어 옮길 수 있는지, 자리 수 −/+로 늘고 줄어드는지(최대 10개), 쉬는 시간이 0.1초씩 바뀌는지
  - 저장하면 하늘색 "순서 N곳" 버튼이 뜨고 모드 버튼이 하늘색이 되는지. 버튼을 누르면 1번부터 순서대로 그 자리가 실제로 눌리는지, 노란 테두리가 누르는 자리를 따라가는지, 버튼이 주황 "2 / 4 멈춤"으로 바뀌는지
  - 실행 중에 버튼을 누르면 바로 멈추는지. 끝나면 "순서 N곳"으로 돌아가는지
  - 실행 버튼을 끌어 옮기면 다음에 켤 때 그 자리에 나오는지
  - 목록에서 다른 순서를 누르면 바뀌는지, "끄기"를 누르면 버튼이 사라지고 모드 버튼이 회색이 되는지
  - 연필 → 자리 다시 잡기: 동그라미가 저장한 자리에 놓여 나오는지. 이름 바꾸기: 키보드가 바로 올라오는지. 삭제: 한 번 더 묻고 지워지는지
  - 5개를 채우면 "+ 새 순서 만들기" 대신 "순서는 5개까지 저장할 수 있어요"가 나오는지
  - 앱을 껐다 켜도 저장한 순서가 남아 있는지
  - 순서 클릭을 켠 채 연타·집결이 전처럼 되는지

- 역할 이름 "관리자" → "지휘관": 앱 첫 화면의 탭, 위쪽 역할 표시, 메뉴("지휘관", "지휘관 관리"), 로그인 창, 집결 패널의 안내 글("지휘관 시작 대기 중" 등), 보내는 안내 문구("지휘관 초대", "지휘관 코드")에 "관리자"가 남아 있지 않은지. 탭에서 글자가 잘리지 않는지

- 모드 버튼은 지휘관에게만: 집결장 화면에서는 막대에 모드 버튼이 **안 보이는지**(전에 개방해 둔 폰이어도). 지휘관으로 전환하면 다시 보이는지. 집결장 화면에서 패널 제목을 5번 눌러도 아무 일이 없는지. 헌터나 순서를 켠 채 집결장으로 바꾸면 꺼지는지

- 겹치는 전환 버튼 정리: 지휘관 메뉴에 "일반 화면으로 전환"이 없는지(세 줄만). 일반 화면 미리보기 카드에 파란 "개발자 화면으로 복귀" 버튼이 없고 "위쪽 탭을 눌러 돌아가세요"가 보이는지. 미리보기 중에 집결장·지휘관 탭을 누르면 돌아오는지
