# 할 일

어느 대화에서 작업하든 **먼저 이 파일을 읽고**, 제안·결정·끝낸 일을 여기에 적는다.
끝낸 일은 "끝낸 일"로 옮기고 커밋 번호(앞 7자리)를 붙인다. 번호는 바꾸지 않는다(대화에서 번호로 부른다).

## 폰에서 확인할 것

자동 테스트는 통과했지만 폰에서 아직 확인하지 못한 것. 확인되면 지운다.

- 복사 버튼을 눌렀을 때 "복사했어요" 알림이 한 번만 뜨는지 (9dce177)
- 미배정 군단이 참여로 체크된 채 "집결 시작"을 누르면 확인 창(미배정 제외하고 시작 / 그대로 시작 / 취소)이 뜨는지, 미배정 글씨가 노랑인지 (2ef710a)
- 관리자 목록 보내기: 미리보기가 보이고 "카카오톡으로 보내기"로 대화방 고르기가 열리는지 (9dce177)

## 사용자 결정이 필요한 것

되돌리기 어렵거나 큰 일이라 승인받고 한다.

- **D. 집결장 코드를 서버 관리로 옮길지**: 지금은 기한이 없고 회수할 수 없다. 관리자 코드처럼 기한·1회 사용·삭제가 되게 하려면 인증 방식을 바꿔야 한다(큰 작업, 기존 집결장 재등록 필요).
- **E. 서버 규칙 파일 하나로 합치기**: `firebase.json`이 옛 `database.rules.json`을 가리킨다. 지금 서버에 게시된 규칙이 어느 쪽인지 먼저 확인해야 한다.
- **5. 다 쓴 브랜치 지우기**: GitHub에 브랜치가 86개 쌓여 있다. `main`에 이미 합쳐진 것만 지우고, 앞으로는 합치면 바로 지운다.
- **7. 저장소 공개 상태**: 누구나 코드를 볼 수 있고, 옛 서명 키가 예전 기록에 남아 있다. 비공개 전환이나 서명 키 새로 만들기를 검토한다(GitHub 설정은 사용자가 직접).
- **6. 사용 매뉴얼 갱신**: 매뉴얼 두 개("집결 사용 매뉴얼", "사용 매뉴얼")를 화면이 바뀔 때 함께 고칠지, 하나로 합칠지.

- **6.** 알림 문구 말투를 "~해요"로 맞추고 이모지는 ⚠·✓ 정도만 남기기. "서버를 확인하는 중…" 같은 안내는 창 안에 표시.
- **13.** 편집 화면의 "먼저"·"+20초"를 "가장 먼저 클릭"·"20초 뒤 클릭"으로.

### 앱 화면 (시안 먼저)

- **3.** 연타 설정(클릭 주기·반복 조건)이 앱 첫 화면과 게임 위 설정 창 두 군데에 있다. 첫 화면은 요약 한 줄만. 투명도 조절도 세 군데 중 하나 줄이기.
- **4.** 보내기 방식 통일: 방 번호·집결장 코드·관리자 코드도 관리자 목록처럼 "카카오톡으로 보내기 + 복사 + 다른 앱".
- **5.** 관리자 카드 높이 줄이기: "이름 수정"·"삭제"를 이름 줄 오른쪽으로.
- **7.** 관리자 관리 위쪽 버튼: "목록 보내기"→"관리자 목록 보내기", "코드 정리"는 "대기 중인 코드" 제목 옆으로.
- **8.** 인증 창: 관리자 로그인에 "이미 등록된 기기예요" 버튼을 따로 두기. (집결장 인증을 코드 하나로 줄이는 것은 위 D와 같은 일)
