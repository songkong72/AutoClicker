끝낸 일은 "끝낸 일"로 옮기고 커밋 번호(앞 7자리)를 붙인다. 번호는 바꾸지 않는다(대화에서 번호로 부른다).

## 폰에서 확인할 것

자동 테스트는 통과했지만 폰에서 아직 확인하지 못한 것. 확인되면 지운다.

- 순서 클릭과 모드 버튼(시안 "단순화 시안" 6·7·8번):
  - 막대: 개방하지 않은 폰에서는 모드 버튼이 **안 보이는지**. 집결 패널 제목을 5번 연달아 누르면 "숨은 모드가 열렸어요" 알림과 함께 목록 모양 "모드" 버튼이 나타나는지. 전에 헌터를 개방해 둔 폰에서는 바로 보이는지
  - "모드 고르기" 글자 옆에 버전(예: 1.0.252)이 보이는지. 헌터를 켜면 모드 버튼이 초록, 순서를 켜면 하늘색, 끄면 회색이 되는지(2026-10-10 사용자 보고: 켜도 회색 그대로. 원인을 코드에서 찾지 못해 색 지정 방법을 하나 더 넣음)
  - 모드 버튼을 누르면 가운데에 "모드 고르기" 목록(헌터 / 저장한 순서 / + 새 순서 만들기 / 끄기)이 뜨고, 목록 밖을 누르면 닫히는지
  - 목록 창·연필 메뉴·삭제 확인 창을 잡고 끌면 옮겨지고 화면 밖으로 나가지 않는지. 옮긴 뒤 연필을 누르면 같은 자리에 다음 창이 뜨는지. 끌지 않고 짧게 누르면 줄이 그대로 눌리는지
  - 헌터: 줄을 누르면 전처럼 켜지고 버튼이 목록 모양 그대로 초록색이 되는지(깃발 그림으로 바뀌지 않음), 연필을 누르면 헌터 위치 잡기 창이 뜨는지, 발사가 전처럼 되는지
  - 새 순서 만들기: 창에 이름 칸·자리 수·자리 사이 쉬는 시간·저장이 보이고 글자가 잘리지 않는지. 이름 칸을 누르면 키보드가 올라오고 한글이 적히는지, 키보드가 창을 가려 불편하지 않은지
  - 번호 동그라미(하늘색)를 끌어 옮길 수 있는지, 자리 수 −/+로 늘고 줄어드는지(최대 10개), 쉬는 시간이 0.1초씩 바뀌는지
  - 저장하면 하늘색 "순서 N곳" 버튼이 뜨고 모드 버튼이 하늘색이 되는지. 버튼을 누르면 1번부터 순서대로 그 자리가 실제로 눌리는지, 노란 테두리가 누르는 자리를 따라가는지, 버튼이 주황 "2 / 4 멈춤"으로 바뀌는지
  - 실행 중에 버튼을 누르면 바로 멈추는지. 끝나면 "순서 N곳"으로 돌아가는지
  - 실행 버튼을 끌어 옮기면 다음에 켤 때 그 자리에 나오는지
  - 목록에서 다른 순서를 누르면 바뀌는지, "끄기"를 누르면 버튼이 사라지고 모드 버튼이 회색이 되는지
  - 연필 → 자리 다시 잡기: 동그라미가 저장한 자리에 놓여 나오는지. 이름 바꾸기: 키보드가 바로 올라오는지. 삭제: 한 번 더 묻고 지워지는지
  - 5개를 채우면 "+ 새 순서 만들기" 대신 "순서는 5개까지 저장할 수 있어요"가 나오는지
  - 앱을 껐다 켜도 저장한 순서가 남아 있는지
  - 순서 클릭을 켠 채 연타·집결이 전처럼 되는지

- 역할 이름 "관리자" → "지휘관": 앱 첫 화면의 탭, 위쪽 역할 표시, 메뉴("지휘관", "지휘관 관리"), 로그인 창, 집결 패널의 안내 글("지휘관 시작 대기 중" 등), 보내는 안내 문구("지휘관 초대", "지휘관 코드")에 "관리자"가 남아 있지 않은지. 탭에서 글자가 잘리지 않는지

- 모드 버튼은 지휘관에게만: 집결장 화면에서는 막대에 모드 버튼이 **안 보이는지**(전에 개방해 둔 폰이어도). 지휘관으로 전환하면 다시 보이는지. 집결장 화면에서 패널 제목을 5번 눌러도 아무 일이 없는지. 헌터나 순서를 켠 채 집결장으로 바꾸면 꺼지는지

- 겹치는 전환 버튼 정리: 지휘관 메뉴에 "일반 화면으로 전환"이 없는지(세 줄만). 일반 화면 미리보기 카드에 파란 "개발자 화면으로 복귀" 버튼이 없고 "위쪽 탭을 눌러 돌아가세요"가 보이는지. 미리보기 중에 집결장·지휘관 탭을 누르면 돌아오는지

- 소속(서버·연맹)별 방 나누기(시안 "단순화 시안" 10번). **모든 폰이 새 버전이어야 서로 보인다.**
  - 앱 첫 화면의 "집결 방" 옆에 회색 "소속 정하기 ›" 표시가 보이는지. 누르면 "소속 정하기" 창(서버 번호, 연맹, 취소·저장)이 뜨는지
  - 연맹 칸: 키보드가 첫 글자를 멋대로 대문자로 바꾸지 않는지, 적은 대소문자 그대로 저장되는지. 기호나 띄어쓰기를 넣으면 안내가 뜨고 저장되지 않는지
  - 저장하면 표시가 "2000 · WBI ›"로 바뀌고, 들어와 있던 방에서 나오는지("방을 골라 주세요")
  - 지휘관: "새 방 만들기"로 1111을 만들면 목록에 1111로 보이는지. 개발자의 "지휘관 관리 → 방 전체 목록"에는 `2000-WBI-1111`로 보이는지
  - 집결장(같은 소속): 방 목록에 그 방이 보이고 입장·명단 등록이 되는지. 집결 시작·취소·행군 시간 변경이 전처럼 되는지
  - 다른 소속으로 정한 폰: 그 방이 목록에 **안 보이고**, 같은 번호 1111을 만들어도 서로 다른 방인지. `wbi`(소문자)로 정한 폰도 다른 소속인지
  - "번호 공유"와 집결장 코드 안내 글에 "소속: 2000 서버 · WBI" 줄이 들어가는지
  - 소속을 정하지 않은 폰에서 "집결 화면 열기"나 막대의 깃발을 누르면 소속부터 정하라고 하는지
  - 예전 방(소속 없는 1111 등)이 새 버전의 방 목록에 안 보이는지

- 소속에 묶인 지휘관·연맹 대표·대표 신청(시안 11·12·13번). **서버 규칙은 2026-10-10에 게시됨(d42f404).** 아래를 폰에서 확인한다.
  - 게시 직후: 기존 지휘관이 방 만들기·시작·취소를 전처럼 할 수 있는지(끊기면 바로 알려 주기)
  - 개발자 "지휘관 관리": 지휘관마다 소속 줄이 보이는지(없으면 주황 "소속 없음"). "소속 정하기"로 정하면 줄이 바뀌는지
  - 소속이 정해진 지휘관 폰: 앱을 다시 열면 소속 표시가 "2000 · WBI 🔒"가 되고, 눌러도 바뀌지 않는지. 자기 소속의 방은 만들고 고칠 수 있는지
  - "새 지휘관 코드": 서버 번호·연맹 칸과 "연맹 대표로 지정" 버튼이 보이는지. 만든 코드의 안내 글에 소속이 들어가는지. 그 코드로 등록한 폰이 그 소속으로 잠기는지
  - 연맹 대표 폰: 지휘관 메뉴에 "우리 연맹 지휘관"이 보이는지. 코드 만들기, 목록(n / 5명), 지휘관 삭제, 대기 코드 보내기·취소가 되는지. 5명이 차면 만들기가 막히는지
  - 일반 지휘관 폰: 메뉴에 "우리 연맹 지휘관"이 **없는지**
  - 대표 신청: 지휘관 로그인 창의 파란 테두리 버튼 "우리 연맹 대표 신청하기" → 신청 창(서버 번호, 연맹, 캐릭터명, 한마디). 신청하면 첫 화면 카드가 "연맹 대표 승인 대기 중"이 되는지. "승인됐는지 확인"으로 상태 창이 뜨고 신청 취소가 되는지
  - 개발자: "지휘관 관리"에 "연맹 대표 신청 n건" 버튼이 보이는지. 승인하면 신청자 폰이 "승인됐는지 확인"을 눌렀을 때 지휘관 화면으로 바뀌고 대표 메뉴가 보이는지. 거절하면 신청자에게 이유가 보이는지
  - 같은 연맹 신청이 겹치거나 이미 대표가 있으면 주황 주의 줄이 보이는지

## 사용자 결정이 필요한 것

되돌리기 어렵거나 큰 일이라 승인받고 한다.

- **D. 집결장 코드를 서버 관리로 옮길지**: 지금은 기한이 없고 회수할 수 없다. 지휘관 코드처럼 기한·1회 사용·삭제가 되게 하려면 인증 방식을 바꿔야 한다(큰 작업, 기존 집결장 재등록 필요).
- **E. 서버 규칙 파일 하나로 합치기**: `firebase.json`이 옛 `database.rules.json`을 가리킨다. 지금 서버에 게시된 규칙이 어느 쪽인지 먼저 확인해야 한다.
- **5. 다 쓴 브랜치 지우기**: GitHub에 브랜치가 86개 쌓여 있다. `main`에 이미 합쳐진 것만 지우고, 앞으로는 합치면 바로 지운다.
- **7. 저장소 공개 상태**: 누구나 코드를 볼 수 있고, 옛 서명 키가 예전 기록에 남아 있다. 비공개 전환이나 서명 키 새로 만들기를 검토한다(GitHub 설정은 사용자가 직접).
- **6. 사용 매뉴얼 갱신**: 매뉴얼 두 개("집결 사용 매뉴얼", "사용 매뉴얼")를 화면이 바뀔 때 함께 고칠지, 하나로 합칠지. 2026-10-10에 새 문서 "오토클리커 Pro 역할과 권한 매뉴얼"(역할별 권한, 집결장·지휘관·연맹 대표가 되는 절차, 한계)을 만들었다. 옛 매뉴얼 두 개는 아직 "관리자"·"팀장" 같은 옛 말을 쓴다. 고칠지 없앨지 사용자 답을 기다리는 중.

### 확인이 필요한 동작

- 시작 확인 창에서 "미배정 제외하고 시작"을 누르면 미배정 군단이 "제외"로 바뀐다. 나중에 사람을 배정해도 제외는 자동으로 풀리지 않아, 군단이 모두 제외된 채 남을 수 있다(2026-10-09 사용자가 겪은 "다시 집결이 안 눌림"의 원인으로 추정, 확인은 못 함). 배정하면 제외를 풀지, 그대로 둘지 정해야 한다.

### 글자·이름 (시안 없이 가능)

- **6-나머지.** "서버를 확인하는 중…", "방 목록을 불러오는 중…" 같은 안내를 잠깐 뜨는 알림 대신 창 안에 표시하기(동작이 바뀌어 따로 처리).
- 버튼·제목에 남은 이모지("🚀 오토클리커 띄우기", "🛑 치료 연타 즉시 정지", "🔒 …", "👑 지휘관 모드" 등)는 그대로 두었다. 뺄지는 화면 모양이 바뀌므로 시안과 함께 정한다.

### 앱 화면 (시안 먼저)

- **5.** 지휘관 카드 높이 줄이기: "이름 수정"·"삭제"를 이름 줄 오른쪽으로.

- **8.** 인증 창: 지휘관 로그인에 "이미 등록된 기기예요" 버튼을 따로 두기. (집결장 인증을 코드 하나로 줄이는 것은 위 D와 같은 일)
