# 🎮 게임용 종합 오토클리커 Pro (AutoClicker Pro)

게임 플레이 중 반복적인 치료 버튼 연타를 **완전 백그라운드로 처리하여, 실제 마우스 커서는 단 1픽셀도 건드리지 않고 웹서핑, 유튜브, 다른 창 작업을 100% 자유롭게** 할 수 있는 독립 실행 프로그램입니다.

---

## ⚡ 빠른 시작 (실행 방법)

폴더 안에 있는 **[`AutoClicker.exe`](file:///e:/project/workspace/AutoClicker/AutoClicker.exe)** 파일을 더블 클릭하시면 즉시 실행됩니다!
- *Python 설치 여부와 상관없이 어느 PC에서나 바로 더블 클릭으로 켜집니다.*
- *바탕화면에 '바로가기'를 만들어두시면 더욱 편리합니다.*

---

## 🎯 치료 연타 중 내 마우스 100% 자유 작업하기 (초간단 사용법)

1. **치료 버튼 딱 1번 찍기**:
   - 키보드의 **`F8`** 키(또는 프로그램 내 `[🎯 치료 버튼 1회 클릭하여 위치 등록]` 버튼)를 누릅니다.
   - 게임 화면으로 가서 **치료 버튼을 마우스로 '딱 1번' 클릭**합니다!
   - *"삑!" 소리와 함께 해당 게임 창과 버튼 위치가 자동 등록 완료됩니다.*

2. **백그라운드 무한 연타 시작**:
   - 클릭 간격은 기본값 **`0.5초`**(원하는 시간으로 조절 가능)로 설정되어 있습니다.
   - 이제 키보드의 **`F6`** 키를 누릅니다.

3. **마우스로 다른 작업 마음껏 하기**:
   - **실제 마우스 커서는 전혀 움직이지 않습니다!**
   - 마우스를 자유롭게 움직여 웹서핑, 유튜브 감상, 카카오톡, 문서 작성 등 원하는 작업을 마음껏 하셔도 **게임 창 안에서만 0.5초마다 치료 버튼이 백그라운드로 계속 연타**됩니다.

4. **멈추기**:
   - 다시 **`F6`** 키를 누르면 즉시 멈춥니다.

---

## 💾 매크로 프리셋 영구 저장 & 다음에 1초 만에 불러오기

- **저장하기**: 상단 `저장할 이름:`에 이름(예: `치료_백그라운드`)을 적고 **`[💾 현재 설정 저장]`** 버튼 클릭!
- **불러오기**: 다음번에 게임할 때 `저장된 프리셋:` 드롭다운에서 선택 후 **`[📥 불러와 적용]`**만 누르면 즉시 1초 만에 복원되어 바로 `F6`으로 사용할 수 있습니다.
