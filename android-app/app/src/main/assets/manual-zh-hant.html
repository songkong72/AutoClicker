1準備

應用程式需要一項權限才能替你點擊遊戲。所有角色的做法都一樣。

  1. 在應用程式首頁的 允許點擊螢幕 卡片上點 去設定。
  2. 閱讀說明並同意。手機的無障礙設定會開啟。
  3. 在列表中找到 AutoClicker，開啟它的開關。
  4. 回到應用程式。看到 已允許點擊螢幕 就完成了。
重啟手機或更新應用程式後，開關可能會被關掉。如果按鈕沒有反應，請在無障礙中把它關掉再開啟。

2連點

按固定的間隔反覆點擊同一個位置。任何人都可以不驗證直接使用。

  1. 點 普通連點模式 卡片，開啟連點設定。
  2. 選擇點擊間隔（0.1秒、0.2秒、0.5秒、1.0秒，或自己輸入）。
  3. 選擇重複條件：無限 一直點擊，次數 點滿次數後停止，時間 到設定時間後停止。
  4. 點 套用，然後點 顯示 AutoClicker。
  5. 把出現在遊戲上的準星拖到想點擊的位置。
  6. 點懸浮條上的 ▶ 開始。再點一次停止。
緊急停止 · 連點時按音量鍵會立即停止。

3集結原理

每支隊伍到達城堡需要的時間（行軍時間）不同。要同時到達，遠的隊伍要先點，近的隊伍後點。這些計算和點擊都由應用程式來做。

4集結隊長

從指揮官那裡拿到代碼，驗證後進入房間，負責自己的隊伍。

只做一次：驗證並進入房間

  1. 隊長把你的 ID 告訴指揮官。電子郵件或暱稱都可以。
  2. 指揮官生成代碼並把文字發給你。裡面有 ID、集結隊長代碼、所屬和房間號。
  3. 隊長把文字整段複製，然後在應用程式首頁點 驗證。各項已經自動填好，確認後點按鈕。
  4. 在 集結房間 卡片上點 請選擇房間，選擇指揮官告訴你的房間。
  5. 輸入遊戲裡的角色名。它會顯示在指揮官的名單上。
  6. 指揮官把你分配到一支隊伍。你的那一行會顯示 我 標記。
集結隊長代碼是 AC- 加6個字元，並且與你的 ID 和所屬綁定。ID 請按原樣填寫。驗證後，你的所屬會鎖定為指揮官的所屬。

集結之前：儲存點擊位置

  1. 點應用程式底部的 開啟集結面板，切換到遊戲。
  2. 在遊戲裡進入能看到集結按鈕的畫面。
  3. 把準星拖到集結按鈕上。
  4. 在集結面板底部開啟 我的裝置 ▾，點 儲存位置。看到 ✓ 位置已儲存 就設好了。
  5. 把自己隊伍的行軍時間設為遊戲裡顯示的數值（−/+ 每次1秒，點數字可以直接輸入）。
請確認 · 如果看到黃色的「請先儲存點擊位置」或「請先登記角色名」，點它就會直接帶你過去。

集結開始時

  • 指揮官開始後，大數字會倒數到你的點擊。
  • 這段時間你必須停在能看到集結按鈕的畫面。應用程式只會點擊儲存的位置。
  • 到0時應用程式替你點擊。之後會顯示「✓ 已點擊」和時間。
  • 如果面板擋住了畫面，點頂部的 – 把它收成小條。倒數仍然看得到。

「我的裝置」一欄

專案作用
房間換到其他房間。
角色名修改名單上顯示的名字。
校正 −/+把這台手機的點擊以0.5秒為單位提前或推後（−5秒到+5秒）。點數字可以直接輸入。
儲存位置把準星現在的位置儲存為集結點擊位置。

5指揮官

建立房間、編排隊伍並開始集結。為集結隊長生成代碼。

成為指揮官

  1. 從聯盟代表那裡拿到指揮官代碼（AD- 加8個字元）。
  2. 點應用程式首頁右上角的鑰匙，開啟 指揮官登入。
  3. 輸入代碼後點確定。頂部會出現 集結隊長 / 指揮官 標籤。
  4. 之後只要點 指揮官 標籤即可，不需要代碼。
指揮官代碼只能使用一次，並且有期限（代表生成的代碼為24小時）。所屬包含在代碼裡，會自動設定，不能更改。

建立房間並編排隊伍

  1. 點 請選擇房間 → 建立新房間。每個所屬最多10個房間。
  2. 點 分享房間號，把房間號發給集結隊長。
  3. 點 開啟集結面板，再點面板頂部的鉛筆進入編輯。
  4. 點 + 新增隊伍 建立隊伍（每個房間最多10支）。
  5. 點隊伍那一行展開，選擇負責人並輸入行軍時間。
  6. 在房間設定中設定集結時間（3、5或10分鐘）和準備時間（每次1秒）。
  7. 點 完成 關閉編輯。每次修改都會立即儲存並傳給所有人。
列表一次顯示 5支隊伍，其餘的在列表內滾動檢視。點 房間設定 ▾ 把它收起，列表就會相應變長。收起的那一行仍然顯示數值。

開始與取消

  • 點 開始集結，所有手機同時開始倒數。只需開始一次。
  • 如果參加的隊伍中有未分配的，應用程式會詢問：排除未分配後開始 / 直接開始 / 取消。
  • 進行中，同一個按鈕變成 取消集結。還沒點擊的手機將不再點擊。
  • 到達或取消之後，按鈕變成 重新集結。不需要重新輸入設定。
  • 集結進行中不能修改隊伍和時間。
防止誤點 · 取消後的1.5秒內，同一位置的「重新集結」不會響應。

為集結隊長生成代碼

  1. 向集結隊長要他的 ID。
  2. 在 集結房間 卡片上點 管理 → 發放集結隊長代碼。
  3. 輸入 ID，點 生成集結隊長代碼。
  4. 把文字發出去。對方整段複製後進行驗證。
請注意 · 集結隊長代碼沒有期限，也無法收回。要讓某人退出，請把他從隊伍中取消分配。

6分波 指揮官

把隊伍分成幾波，讓各波間隔一段時間到達。同一波的隊伍同時到達，從第2波起，每一波比第1波晚設定的時間到達。

編輯使用分波的房間
第1波2支隊伍最先到達（基準）
1隊Moon10秒
2隊AngryBird30秒
第2波1支隊伍−  2分後到達  +
3隊Cart50秒
  1. 進入編輯後點 分波，按隊伍編號順序分組，每波2、3或5支。選擇全部歸入第1波可以取消分波。
  2. 要移動某一支隊伍，展開它的那一行，選擇 第1波 到 第5波。
  3. 用每一波標題上的 −/+ 設定間隔：每次10秒，從0秒到10分鐘。點數值可以直接輸入。
  4. 開始集結 只需點一次。後面幾波的手機會相應晚一些點擊。
規則內容
波數第1波到第5波。每一波的隊伍數不限（整個房間最多10支）。
間隔的基準始終是第1波。「2分後到達」表示比第1波晚2分鐘。
行軍時間不受影響。保持遊戲裡顯示的數值。
大數字沒有隊伍的指揮官：下一波到達。集結隊長：自己的隊伍。
所有隊伍都在第1波不顯示波的標題。
收起一波點某一波的標題收起它的隊伍，再點一次展開。只在你的手機上收起。
請確認 · 使用分波時，指揮官和集結隊長必須全部使用最新版本。舊版本不知道間隔，會提前點擊。

7聯盟代表

每個聯盟一名。可以做指揮官能做的所有事，還可以指定和移除本聯盟的指揮官。

申請成為代表

  1. 首頁右上角的鑰匙 → 指揮官登入 → 申請成為本聯盟代表。
  2. 填寫伺服器編號、聯盟和遊戲角色名。可以加一句留言（最多60個字，例如：我是 WBI 的盟主）。
  3. 點 申請。首頁會顯示正在等待批准，也可以在那裡取消。
  4. 批准之後再開啟申請視窗，就會切換到指揮官畫面。
批准時不會有通知。請不時開啟應用程式檢視。一台手機只能提交一個申請。

指定本聯盟的指揮官

  1. 點 管理 → 本聯盟指揮官。
  2. 點 + 生成指揮官代碼，輸入備註名，生成代碼後發出去。
  3. 對方在24小時內到指揮官登入中輸入代碼，就成為指揮官。
  4. 要移除某人，在名單上點 刪除。那台手機下次開啟應用程式時會回到集結隊長畫面。
規則內容
每個聯盟的指揮官包括代表在內最多5名。
代表管理的範圍只有自己的聯盟。看不到其他聯盟。
指揮官指定指揮官不可以。只有代表可以指定。
更換代表同一聯盟的其他人提交申請，批准後代表更換。原代表變為普通指揮官。

8所屬（伺服器 · 聯盟）

房間歸在所屬之下。只有相同所屬的人才會在同一個房間裡見面。畫面上顯示為 2000 · WBI。

  • 伺服器編號：最多6位數字。聯盟：最多8個字母和數字。
  • 聯盟區分大小寫。WBI 和 wbi 是不同的所屬。
  • 房間號按所屬分開計算。其他聯盟使用相同的號碼也不會衝突。
  • 更改所屬後，你會離開原來所在的房間。
角色所屬如何設定
集結隊長複製邀請文字並驗證：使用邀請中的所屬並鎖定。要去其他聯盟，請向那個聯盟的指揮官索取新代碼。
指揮官、代表包含在指揮官代碼裡。顯示鎖的圖示，不能更改。
