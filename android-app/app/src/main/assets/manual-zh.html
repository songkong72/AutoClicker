1准备

应用需要一项权限才能替你点击游戏。所有角色的做法都一样。

  1. 在应用首页的 允许点击屏幕 卡片上点 去设置。
  2. 阅读说明并同意。手机的无障碍设置会打开。
  3. 在列表中找到 AutoClicker，打开它的开关。
  4. 回到应用。看到 已允许点击屏幕 就完成了。
重启手机或更新应用后，开关可能会被关掉。如果按钮没有反应，请在无障碍中把它关掉再打开。

2连点

按固定的间隔反复点击同一个位置。任何人都可以不验证直接使用。

  1. 点 普通连点模式 卡片，打开连点设置。
  2. 选择点击间隔（0.1秒、0.2秒、0.5秒、1.0秒，或自己输入）。
  3. 选择重复条件：无限 一直点击，次数 点满次数后停止，时间 到设定时间后停止。
  4. 点 应用，然后点 显示 AutoClicker。
  5. 把出现在游戏上的准星拖到想点击的位置。
  6. 点悬浮条上的 ▶ 开始。再点一次停止。
紧急停止 · 连点时按音量键会立即停止。

3集结原理

每支队伍到达城堡需要的时间（行军时间）不同。要同时到达，远的队伍要先点，近的队伍后点。这些计算和点击都由应用来做。

4集结队长

从指挥官那里拿到代码，验证后进入房间，负责自己的队伍。

只做一次：验证并进入房间

  1. 队长把你的 ID 告诉指挥官。邮箱或昵称都可以。
  2. 指挥官生成代码并把文字发给你。里面有 ID、集结队长代码、所属和房间号。
  3. 队长把文字整段复制，然后在应用首页点 验证。各项已经自动填好，确认后点按钮。
  4. 在 集结房间 卡片上点 请选择房间，选择指挥官告诉你的房间。
  5. 输入游戏里的角色名。它会显示在指挥官的名单上。
  6. 指挥官把你分配到一支队伍。你的那一行会显示 我 标记。
集结队长代码是 AC- 加6个字符，并且与你的 ID 和所属绑定。ID 请按原样填写。验证后，你的所属会锁定为指挥官的所属。

集结之前：保存点击位置

  1. 点应用底部的 打开集结面板，切换到游戏。
  2. 在游戏里进入能看到集结按钮的画面。
  3. 把准星拖到集结按钮上。
  4. 在集结面板底部打开 我的设备 ▾，点 保存位置。看到 ✓ 位置已保存 就设好了。
  5. 把自己队伍的行军时间设为游戏里显示的数值（−/+ 每次1秒，点数字可以直接输入）。
请确认 · 如果看到黄色的“请先保存点击位置”或“请先登记角色名”，点它就会直接带你过去。

集结开始时

  • 指挥官开始后，大数字会倒数到你的点击。
  • 这段时间你必须停在能看到集结按钮的画面。应用只会点击保存的位置。
  • 到0时应用替你点击。之后会显示“✓ 已点击”和时间。
  • 如果面板挡住了画面，点顶部的 – 把它收成小条。倒数仍然看得到。

校正 −/+把这台手机的点击以0.5秒为单位提前或推后（−5秒到+5秒）。点数字可以直接输入。

5指挥官

创建房间、编排队伍并开始集结。为集结队长生成代码。

成为指挥官

  1. 从联盟代表那里拿到指挥官代码（AD- 加8个字符）。
  2. 点应用首页右上角的钥匙，打开 指挥官登录。
  3. 输入代码后点确定。顶部会出现 集结队长 / 指挥官 标签。
  4. 之后只要点 指挥官 标签即可，不需要代码。
指挥官代码只能使用一次，并且有期限（代表生成的代码为24小时）。所属包含在代码里，会自动设定，不能更改。

创建房间并编排队伍

  1. 点 请选择房间 → 创建新房间。每个所属最多10个房间。
  2. 点 分享房间号，把房间号发给集结队长。
  3. 点 打开集结面板，再点面板顶部的铅笔进入编辑。
  4. 点 + 添加队伍 创建队伍（每个房间最多10支）。
  5. 点队伍那一行展开，选择负责人并输入行军时间。
  6. 在房间设置中设定集结时间（3、5或10分钟）和准备时间（每次1秒）。
  7. 点 完成 关闭编辑。每次修改都会立即保存并传给所有人。
列表一次显示 5支队伍，其余的在列表内滚动查看。点 房间设置 ▾ 把它收起，列表就会相应变长。收起的那一行仍然显示数值。

看到的内容含义
蓝色勾选这支队伍参加本次集结。取消勾选后变为排除，显示成一条细行。顺序不变。

小字比最先点击的队伍晚几秒点击。在分波的房间里，只在同一波内比较。
黄色“未分配”没有负责人。没有手机去点击，这支队伍不会出发。
队伍校正在展开的行里，只把这支队伍以0.5秒为单位提前或推后（−5秒到+5秒）。
“删除N队”在展开的行的最下面。点两次删除。

开始与取消

  • 点 开始集结，所有手机同时开始倒数。只需开始一次。
  • 如果参加的队伍中有未分配的，应用会询问：排除未分配后开始 / 直接开始 / 取消。
  • 进行中，同一个按钮变成 取消集结。还没点击的手机将不再点击。
  • 到达或取消之后，按钮变成 重新集结。不需要重新输入设置。
  • 集结进行中不能修改队伍和时间。
防止误点 · 取消后的1.5秒内，同一位置的“重新集结”不会响应。

为集结队长生成代码

  1. 向集结队长要他的 ID。
  2. 在 集结房间 卡片上点 管理 → 发放集结队长代码。
  3. 输入 ID，点 生成集结队长代码。
  4. 把文字发出去。对方整段复制后进行验证。
请注意 · 集结队长代码没有期限，也无法收回。要让某人退出，请把他从队伍中取消分配。

6分波 指挥官

把队伍分成几波，让各波间隔一段时间到达。同一波的队伍同时到达，从第2波起，每一波比第1波晚设定的时间到达。

编辑使用分波的房间
第1波2支队伍最先到达（基准）
1队Moon10秒
2队AngryBird30秒
第2波1支队伍−  2分后到达  +
3队Cart50秒
  1. 进入编辑后点 分波，按队伍编号顺序分组，每波2、3或5支。选择全部归入第1波可以取消分波。
  2. 要移动某一支队伍，展开它的那一行，选择 第1波 到 第5波。
  3. 用每一波标题上的 −/+ 设定间隔：每次10秒，从0秒到10分钟。点数值可以直接输入。
  4. 开始集结 只需点一次。后面几波的手机会相应晚一些点击。
规则内容
波数第1波到第5波。每一波的队伍数不限（整个房间最多10支）。
间隔的基准始终是第1波。“2分后到达”表示比第1波晚2分钟。
行军时间不受影响。保持游戏里显示的数值。
大数字没有队伍的指挥官：下一波到达。集结队长：自己的队伍。
所有队伍都在第1波不显示波的标题。
收起一波点某一波的标题收起它的队伍，再点一次展开。只在你的手机上收起。
请确认 · 使用分波时，指挥官和集结队长必须全部使用最新版本。旧版本不知道间隔，会提前点击。

7联盟代表

每个联盟一名。可以做指挥官能做的所有事，还可以指定和移除本联盟的指挥官。

申请成为代表

  1. 首页右上角的钥匙 → 指挥官登录 → 申请成为本联盟代表。
  2. 填写服务器编号、联盟和游戏角色名。可以加一句留言（最多60个字，例如：我是 WBI 的盟主）。
  3. 点 申请。首页会显示正在等待批准，也可以在那里取消。
  4. 批准之后再打开申请窗口，就会切换到指挥官画面。
批准时不会有通知。请不时打开应用查看。一台手机只能提交一个申请。

指定本联盟的指挥官

  1. 点 管理 → 本联盟指挥官。
  2. 点 + 生成指挥官代码，输入备注名，生成代码后发出去。
  3. 对方在24小时内到指挥官登录中输入代码，就成为指挥官。
  4. 要移除某人，在名单上点 删除。那台手机下次打开应用时会回到集结队长画面。
规则内容
每个联盟的指挥官包括代表在内最多5名。
代表管理的范围只有自己的联盟。看不到其他联盟。
指挥官指定指挥官不可以。只有代表可以指定。
更换代表同一联盟的其他人提交申请，批准后代表更换。原代表变为普通指挥官。

8所属（服务器 · 联盟）

房间归在所属之下。只有相同所属的人才会在同一个房间里见面。画面上显示为 2000 · WBI。

  • 服务器编号：最多6位数字。联盟：最多8个字母和数字。
  • 联盟区分大小写。WBI 和 wbi 是不同的所属。
  • 房间号按所属分开计算。其他联盟使用相同的号码也不会冲突。
  • 更改所属后，你会离开原来所在的房间。
角色所属如何设定
集结队长复制邀请文字并验证：使用邀请中的所属并锁定。要去其他联盟，请向那个联盟的指挥官索取新代码。
指挥官、代表包含在指挥官代码里。显示锁的图标，不能更改。
