1처음 준비

앱이 게임 화면을 대신 누르려면 허용이 한 번 필요합니다. 모든 역할이 똑같이 합니다.

  1. 앱 첫 화면의 화면 터치 허용 카드에서 설정하기를 누릅니다.
  2. 안내를 읽고 동의하면 폰의 접근성 설정이 열립니다.
  3. 목록에서 오토클리커를 찾아 스위치를 켭니다.
  4. 앱으로 돌아와 화면 터치 허용됨이 보이면 끝입니다.
폰을 껐다 켜거나 앱을 업데이트하면 스위치가 꺼질 수 있습니다. 버튼이 반응하지 않으면 접근성에서 껐다가 다시 켜 주세요.

2일반 연타

정한 자리를 일정한 간격으로 계속 눌러 줍니다. 인증 없이 누구나 씁니다.

  1. 일반 연타 모드 카드를 눌러 연타 설정을 엽니다.
  2. 클릭 주기를 고릅니다(0.1초, 0.2초, 0.5초, 1.0초 또는 직접 입력).
  3. 반복 조건을 고릅니다: 무한 계속, 횟수 정한 번수만큼, 시간 정한 시간만큼.
  4. 적용을 누르고 오토클리커 띄우기를 누릅니다.
  5. 게임 위에 뜬 과녁을 누르고 싶은 자리로 끌어다 놓습니다.
  6. 막대의 ▶를 누르면 연타가 시작되고, 다시 누르면 멈춥니다.
급하게 멈추기 · 연타 중에 폰의 볼륨 키를 누르면 바로 멈춥니다.

4집결장

지휘관에게 코드를 받아 인증하고, 방에 들어가 내 군단을 맡습니다.

처음 한 번: 인증하고 방에 들어가기

  1. 집결장지휘관에게 내 ID를 알려 줍니다. 이메일이든 닉네임이든 됩니다.
  2. 지휘관코드를 만들어 카카오톡으로 보내 줍니다. 글에 ID, 집결장 코드, 소속, 방 번호가 들어 있습니다.
  3. 집결장받은 글을 통째로 복사한 뒤 앱 첫 화면의 인증하기를 누릅니다. 칸이 저절로 채워져 있으니 확인하고 버튼을 누릅니다.
  4. 첫 화면 집결 방 카드의 방 선택에서 지휘관이 알려 준 방을 고릅니다.
  5. 게임 캐릭터명을 적습니다. 지휘관의 명단에 이 이름이 올라갑니다.
  6. 지휘관나를 군단에 배정합니다. 배정되면 내 줄에 나 표시와 왼쪽 파란 띠가 붙어 한눈에 찾을 수 있습니다.
집결장 코드는 AC- 뒤에 6자리이고, ID와 소속에 묶여 있습니다. 받은 ID 그대로 적어야 맞고, 인증하면 소속이 지휘관의 소속으로 잠깁니다.

집결 전에: 클릭 위치 저장

  1. 앱 아래의 집결 화면 열기를 누르고 게임으로 갑니다.
  2. 게임에서 집결 버튼이 보이는 화면까지 갑니다.
  3. 과녁을 집결 버튼 위로 끌어다 놓습니다.
  4. 집결 화면 아래의 내 기기 ▾를 펴고 위치 저장을 누릅니다. ✓ 위치 저장됨이 보이면 됩니다.
  5. 내 군단 줄의 행군 시간을 게임에 보이는 값과 같게 맞춥니다(−/+ 는 1초씩, 숫자를 누르면 직접 입력).
꼭 확인 · 노란 글씨 "클릭 위치를 먼저 저장하세요"나 "캐릭터명을 먼저 등록하세요"가 보이면 그 글씨를 누르세요. 바로 그 입력으로 갑니다.

집결이 시작되면

  • 지휘관이 시작하면 큰 숫자가 내 클릭까지 남은 시간을 셉니다.
  • 그 사이에 게임에서 집결 버튼이 보이는 화면에 가 있어야 합니다. 앱은 저장해 둔 자리를 누를 뿐입니다.
  • 숫자가 0이 되면 앱이 대신 누릅니다. 누른 뒤에는 "✓ 클릭함"과 시각이 보입니다.
  • 화면이 좁으면 위의 –를 눌러 알약 모양으로 접습니다. 남은 시간은 계속 보입니다.

5지휘관

방을 만들고, 군단을 짜고, 집결을 시작합니다. 집결장에게 코드를 만들어 줍니다.

지휘관 되기

  1. 연맹 대표에게 지휘관 코드(AD- 뒤에 8자)를 받습니다.
  2. 앱 첫 화면 오른쪽 위의 열쇠를 눌러 지휘관 로그인을 엽니다.
  3. 코드를 적고 확인을 누릅니다. 위쪽에 집결장 / 지휘관 탭이 생깁니다.
  4. 다음부터는 코드 없이 지휘관 탭만 누르면 됩니다.
지휘관 코드는 한 번만 쓸 수 있고 기한이 있습니다(대표가 만든 코드는 24시간). 소속은 코드에 들어 있어 자동으로 정해지고 바꿀 수 없습니다.

방 만들고 군단 짜기

  1. 방 선택 → + 새 방 만들기로 방을 만듭니다. 방은 소속마다 10개까지입니다.
  2. 번호 공유로 방 번호를 집결장들에게 알립니다.
  3. 집결 화면 열기 → 집결 화면 위의 연필을 눌러 편집을 엽니다.
  4. + 군단 추가로 군단을 만듭니다(방마다 10개까지).
  5. 군단 줄을 눌러 펼친 뒤 맡을 사람을 고르고 행군 시간을 넣습니다.
  6. 아래 방 설정에서 집결 대기(3분·5분·10분)와 이동 준비(1초씩)를 정합니다.
  7. 완료를 눌러 편집을 닫습니다. 값은 누르는 즉시 저장되어 모두에게 전달됩니다.
군단 목록은 한 번에 군단 5줄까지 보이고 나머지는 목록 안에서 밀어 봅니다. 방 설정 ▾을 눌러 접으면 그만큼 목록이 길어집니다. 접힌 줄에도 값은 보입니다.

집결 시작과 취소

  • 집결 시작을 누르면 모든 폰이 동시에 세기 시작합니다. 시작은 한 번이면 됩니다.
  • 참여 군단 중 미배정이 있으면 물어봅니다: 미배정 제외하고 시작 / 그대로 시작 / 취소.
  • 진행 중에는 같은 자리가 집결 취소로 바뀝니다. 취소하면 아직 누르지 않은 폰은 누르지 않습니다.
  • 도착하거나 취소한 뒤에는 다시 집결이 됩니다. 설정을 다시 넣을 필요가 없습니다.
  • 진행 중에는 군단과 시간을 고칠 수 없습니다.
잘못 누름 방지 · 취소 직후 1.5초 동안은 같은 자리의 "다시 집결"이 눌리지 않습니다.

집결장 코드 만들어 주기

  1. 집결장에게 ID를 받습니다.
  2. 집결 방 카드의 관리 → 집결장 코드 발급을 엽니다.
  3. ID를 적고 집결장 코드 만들기를 누릅니다.
  4. 만들어진 글을 카카오톡으로 보냅니다. 받은 사람은 통째로 복사해서 인증합니다.
알아 둘 것 · 집결장 코드는 기한이 없고 회수할 수 없습니다. 내보낼 때는 군단 배정에서 빼 주세요.

6조 나누기 지휘관

군단을 조로 묶어 시간 차이를 두고 도착시킵니다. 같은 조는 같이 도착하고, 2조부터는 "1조보다 몇 초 뒤"에 도착합니다.

조를 쓰는 방의 편집 화면
1조군단 2개먼저 도착 (기준)
1군문10초
2군앵그리버드30초
2조군단 1개−  2분 뒤 도착  +

  1. 편집을 열고 조 나누기를 누르면 번호 순으로 2개씩 · 3개씩 · 5개씩 묶습니다. 모두 1조로를 고르면 조가 없어집니다.
  2. 한 군단만 옮기려면 그 줄을 펼쳐 1조 ~ 5조 중에서 고릅니다.
  3. 조 머리띠의 −/+ 로 도착 간격을 정합니다. 10초씩, 0초부터 10분까지. 값을 누르면 직접 입력합니다.
  4. 집결 시작은 한 번만 누릅니다. 뒤 조의 폰은 그만큼 늦게 누릅니다.
정해 둔 것값
조의 수1조 ~ 5조. 한 조의 군단 수는 자유(방 전체 10개까지).
도착 간격의 기준항상 1조. "2분 뒤 도착"은 1조보다 2분 뒤입니다.
행군 시간건드리지 않습니다. 게임에 보이는 값 그대로 둡니다.
큰 숫자군단이 없는 지휘관: 다음에 도착할 조. 집결장: 내 군단 기준.
모두 1조일 때조 머리띠가 보이지 않습니다.
조 상자조 머리띠는 군단 줄보다 진하게 보이고, 그 조의 군단 줄은 안으로 들어가 왼쪽 세로 선으로 머리띠와 이어집니다. 다음 조는 간격을 두고 새 상자로 시작합니다.
조 접기조 머리띠를 누르면 그 조의 군단 줄이 접히고, 다시 누르면 펴집니다. 내 폰에서만 접히고 다른 사람 화면은 그대로입니다.
꼭 확인 · 조를 쓰려면 지휘관과 집결장 모두 최신 버전이어야 합니다. 옛 버전 폰은 도착 간격을 몰라 일찍 누릅니다.

7연맹 대표

연맹마다 한 명입니다. 지휘관이 하는 일 전부에 더해, 우리 연맹의 지휘관을 정하고 뺍니다.

대표 신청하기

  1. 첫 화면 오른쪽 위 열쇠 → 지휘관 로그인 → 우리 연맹 대표 신청하기.
  2. 서버 번호, 연맹, 게임 캐릭터명을 적습니다. 한마디(60자까지, 예: WBI 맹주입니다)를 붙일 수 있습니다.
  3. 신청하기를 누르면 첫 화면에 "승인을 기다리는 중"이 보입니다. 여기서 취소할 수 있습니다.
  4. 승인된 뒤 신청 창을 다시 열면 지휘관 화면으로 바뀝니다.
승인 알림은 오지 않습니다. 가끔 열어서 확인해 주세요. 한 폰에서 신청은 하나만 됩니다.

우리 연맹 지휘관 정하기

  1. 관리 → 우리 연맹 지휘관을 엽니다.
  2. + 지휘관 코드 만들기에서 이름표를 적고 코드를 만들어 보냅니다.
  3. 받은 사람이 24시간 안에 지휘관 로그인 창에 코드를 넣으면 지휘관이 됩니다.
  4. 뺄 때는 명단에서 삭제를 누릅니다. 그 폰은 다음에 앱을 열 때 집결장 화면으로 돌아갑니다.
정해 둔 것값
한 연맹의 지휘관대표를 포함해 5명까지.
대표가 다루는 범위자기 연맹만. 다른 연맹은 보이지 않습니다.
지휘관이 지휘관을 정하기안 됩니다. 대표만 정합니다.
대표가 바뀔 때같은 연맹의 다른 사람이 대표 신청을 하고 승인되면 바뀝니다. 예전 대표는 일반 지휘관이 됩니다.

8소속 (서버 · 연맹)

방은 소속 아래에 있습니다. 소속이 같은 사람끼리만 같은 방에서 만납니다. 화면에는 2000 · WBI처럼 보입니다.

  • 서버 번호는 숫자 6자리까지, 연맹은 글자와 숫자 8자까지.
  • 연맹은 대문자와 소문자를 구분합니다. WBI와 wbi는 서로 다른 소속입니다.
  • 방 번호는 소속마다 따로입니다. 다른 연맹이 같은 번호를 써도 겹치지 않습니다.
  • 소속을 바꾸면 들어와 있던 방에서 나옵니다.
역할소속이 정해지는 방법
집결장초대 글을 복사해서 인증하면 그 글의 소속으로 정해지고 잠깁니다. 다른 연맹으로 가려면 그 연맹 지휘관에게 새 코드를 받습니다.
지휘관, 대표받은 지휘관 코드에 들어 있습니다. 자물쇠가 붙고 바꿀 수 없습니다.

버튼을 눌러도 게임이 눌리지 않는다접근성에서 오토클리커를 껐다가 다시 켭니다. 처음 준비 보기
"집결장 코드로 인증한 뒤에 쓸 수 있어요"아직 인증 전입니다. 집결장 보기
코드가 맞지 않는다고 나온다ID를 받은 그대로 적었는지, 연맹의 대문자·소문자가 같은지 봅니다. 예전 방식 코드는 받지 않으니 새로 받습니다.
방 목록에 우리 방이 없다소속(서버·연맹)이 지휘관과 같은지 봅니다. 소속 보기
내 이름이 지휘관 명단에 없다방에 들어갔는지, 캐릭터명을 적었는지 봅니다. 그래도 없으면 방을 나갔다 다시 들어갑니다.
시간이 됐는데 누르지 않았다클릭 위치를 저장했는지, 군단에 배정됐는지(내 줄에 "나"), 제외되지 않았는지 봅니다.
남들보다 조금 늦거나 빠르다내 기기의 보정을 0.5초씩 맞춥니다. −는 더 일찍, +는 더 늦게.
"집결 시작"이 흐리다참여하는 군단이 없습니다. 아래 빨간 글씨가 이유를 알려 줍니다.
조를 골랐는데 1조로 돌아온다"조를 저장하지 못했어요"가 뜨면 서버 설정이 아직 준비되지 않은 것입니다. 앱을 만든 사람에게 알려 주세요.
연결 점이 주황이나 빨강이다초록은 실시간, 주황은 1초마다 확인, 빨강은 끊김입니다. 인터넷을 확인합니다.
앱을 지우고 다시 깔았다지휘관과 대표는 새 코드를 받아 다시 등록해야 합니다. 업데이트(덮어 설치)는 그대로 유지됩니다.
화면이 다른 언어로 나와요앱은 폰의 언어를 따릅니다(한국어·영어·중국어 간체·번체, 그 밖의 언어는 한국어). 안드로이드 13 이상은 설정 → 앱 → 오토클리커 Pro → 언어에서 이 앱만 바꿀 수 있습니다.
